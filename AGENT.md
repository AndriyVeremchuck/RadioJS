## 2. Стек технологій (Tech Stack)

- **Мова:** Python 3.10+
- **GUI Framework:** PyQt6
  - `QGridLayout`, `QScrollArea`, `QFrame`, `QDialog`, `QMessageBox`, `QFileDialog`, `QPushButton`, `QLineEdit`, `QLabel`
  - Кастомний рендеринг через `QPainter` (градієнти `QConicalGradient`, анімація пульсуючого контуру `QTimer`)
  - Стилізація: єдиний Dark Theme стиль через `app.setStyle("Fusion")` + `app.setPalette(dark_palette)` + CSS-стилі
- **Аудіо:** `PyQt6.QtMultimedia` (`QMediaPlayer`, `QAudioOutput`) з бекендом `FFmpeg`
- **Дані:** 
  - `stations.json` (~8 000 станцій, 1.7 МБ)
  - `app_state.json` (персистентність кольорів, прослуханих/нових станцій, фільтрів)
  - `station_delete.json` (архів видалених станцій для дедуплікації)

## 3. Детальний опис компонентів та логіки Radio Manager

### 3.1. Візуальні стани карток (`StationWidget`):
1. **Прослухана станція (`has_played == True`):**
   - **Глибокий чорний фон** (`#000000`), темна рамка (`#1c2026`).
   - Темний бейдж із номером та галочкою: `#{idx} ✓`.
   - Зберігається персистентно у `app_state.json` (`played_urls`) та `stations.json` (`has_played: True`).
2. **Не прослухана станція (звичайний стан):**
   - **Темно-сірий фон** (`#282b30`), рамка `#3c4148`.
   - Синій бейдж номера (`#58a6ff`).
3. **Нова станція (`is_new == True` або `_is_imported_new == True`):**
   - **Темно-зелений фон** (`#162d1d`), яскраво-зелена рамка (`#2ea043`).
   - Зелений бейдж зі зірочками: `#{idx} ✨`.
   - Зелена кнопка «Грати» (`#238636`).
   - Зберігається персистентно у `app_state.json` (`new_urls`) та `stations.json` (`is_new: True`).
4. **Станція грає (`is_playing == True`):**
   - Чорний фон (`#000000`) та неонова райдужна пульсуюча рамка (`QConicalGradient` + `QTimer` кожні 45 мс).
   - Зелений бейдж із нотою `🎵` та червона кнопка `⏹ Стоп`.
   - При старті відтворення станція автоматично маркується як прослухана (`has_played = True`).
5. **Позначена на видалення:**
   - Темно-червоний фон (`#441418`), червона рамка (`#ff444f`).
6. **Фокус клавіатури:**
   - Пунктирний синій контур (`#58a6ff`).

### 3.2. Стиль «✨ Нова вкладка»
- Додано до рядка жанрів чіп `("✨ Нова вкладка", "__NEW__")`.
- Спеціальний зелений стиль кнопки (`#122216`, `#3fb950`, `#238636`).
- Фільтрує та відображає виключно нові станції (зелені картки).
- Автоматично активується при імпорті з M3U або ручному додаванні станції (`Insert`).
- **Залишається постійно відкритою** між перезапусками (зберігається в `app_state.json`).

### 3.3. Модальне вікно вибору країн (`CountryMultiSelectDialog`)
- Викликається кнопкою `🌍 Усі країни ▼` у правому блоці панелі фільтрів.
- **5 колонок країн (`COLS = 5`)**.
- **Шрифт удвічі більший (19px bold)**.
- **Без чекбоксів**: сама назва країни світиться яскраво-синім кольором (`#58a6ff`, підкладка `#1f6feb`), якщо країна вибрана, або приглушеним сірим (`#8b949e`), якщо не вибрана.
- Кнопки: «Зняти всі», «Обрати всі», «Готово (Enter)», «Скасувати (Esc)».
- Підтримка мульти-вибору: можна обрати 1, 2, 3 чи довільну кількість країн одночасно.

### 3.4. Панель керування та фільтрів (`FilterBarContainer`)
- **Верхній рядок:**
  - Ліворуч: статистика `Всього: N | Позначено до видалення: M`.
  - По центру: назва треку / станції (копіювання тексту пісні кліком/кнопкою `📋`).
  - Праворуч: кнопка `➕ Додати з M3U`, таймер автопереходу (3–60 сек). *Гучність прибрано на прохання користувача*.
- **Рядок фільтрів:**
  - **Зліва:** Поле пошуку станцій (шрифт 17px, вбудована кнопка очищення). *Кнопку оновлення біля пошуку прибрано*.
  - **По центру:** Повний ряд кнопок-чіпів стилів (Усі, ✨ Нова вкладка, Rock, Pop, Dance, Hits, Folk, Jazz, Classic, News, Retro, Relax, Hip-Hop, Інше).
  - **Справа:** Кнопка вибору країн (модальне вікно) та бейдж кількості знайдених станцій (`N ст.`).
  - **Адаптивність:** Математичне центрування блоку жанрів з динамічним обмеженням для компактних екранів (1366x768).

### 3.5. Персистентність стану (`app_state.json`)
- Файл стану атомарно зберігає:
  - `played_urls`: нормалізовані URL прослуханих станцій (чорний фон).
  - `new_urls`: нормалізовані URL нових станцій (зелений фон).
  - `selected_country_codes`: список обраних кодів країн.
  - `selected_genre_patterns`: список обраних стилів (включаючи `__NEW__`).
  - `last_played_url`: станція, яка грала останньою (для автопозиціонування).

### 3.6. Навігація клавіатурою
- `Tab` / `Shift+Tab`: перемикання між полем пошуку та сіткою карток.
- Стрілки `◀ ▲ ▼ ▶`: переміщення між картками (сітка 4 колонки).
- `Space` / `Enter`: відтворення / пауза.
- `Delete` або `D`: позначити станцію на видалення / зняти позначку.
- `Insert`: додати нову станцію вручну.
- `Home` / `End`, `PgUp` / `PgDn`: швидка навігація списком.
- `Ctrl+F`: фокус на полі пошуку.

## 4. План по оптимізації (Refactoring to SQLite & Virtual Viewport)

Див. детальний план у файлі `PLAN.md` та в артефакті `optimization_and_scalability_plan.md`.

- **Етап 3:** Віртуалізація карток (фіксований пул із 32–40 віджетів для 60 FPS скролінгу).
- **Етап 4:** Асинхронний імпорт M3U та кешування логотипів у фоні (`QThread`).
