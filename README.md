# 🎵 RadioJS

**RadioJS** — це сучасний веб-додаток для онлайн-прослуховування українських радіостанцій.

---

## 🟡 Особливості

- **Близько 40 українських радіостанцій** — національні та регіональні станції з усіх куточків України (включно зі станціями проєкту Radio-Bash).
- **Якісні логотипи** — локальні чіткі логотипи для кожної станції без спотворень.
- **Зручний плеєр** — нижня панель із керуванням гучністю, паузою/відтворенням та статусом потоку.
- **Швидкий пошук** — миттєва фільтрація радіостанцій за назвою або містом.
- **Сучасний інтерфейс** — фонове відео, скляний дизайн (glassmorphism), індикатори активного відтворення.
- **Адаптивність** — зручно працює як на смартфоні, так і на комп’ютері.
- **Відтворення у 1 клік** — просто натискай на станцію, щоб слухати.
- **Без реклами** — лише музика та новини.

---

## 🔥 Початок роботи

1. **Скачайте або склонуйте репозиторій.**
2. Відкрийте `radio.html` у будь-якому браузері (або запустіть локальний сервер, наприклад `python3 -m http.server`).
3. Клікайте по улюбленій радіостанції — і слухайте!

---

## ☑️ Stack

- **HTML5**  
- **CSS3** (CSS Grid, Flexbox, Glassmorphism, анімації)
- **JavaScript** (керування потоковим аудіо, пошук, стан плеєра)
