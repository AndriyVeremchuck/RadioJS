# 🎵 RadioJS & Radio Manager

**RadioJS** — це сучасний мультиплатформенний музичний комбайн для онлайн-прослуховування, керування та каталогізації радіостанцій України та Світу. Проєкт включає стильний веб-плеєр та потужний десктопний додаток **Radio Manager** на базі PyQt6 і FFmpeg.

---

## 🌟 Основні компоненти

### 1. 🌐 Веб-плеєр RadioJS (`index.html`)
- **Швидкий веб-інтерфейс**: плавні світлові неонові плями на темному фоні, що повільно плавають в інтерфейсі.
- **Вбудована бібліотека**: національні та регіональні станції України, топ-станції Європи та США.
- **Анімації та реактивність**: неонове світіння активної станції, делікатне затемнення інших карток, динамічний еквалайзер.
- **Чистий Vanilla JS**: жодних сторонніх важких фреймворків чи реклами — нативний HTML5 Audio API, CSS Grid та векторна графіка SVG.

### 2. 📻 Десктопний додаток Radio Manager (`radio_manager.py`)
Професійний менеджер та аудіоплеєр для великої колекції станцій (понад **7 900+ станцій**):
- **Рівномірна сітка карток**: 4 рівні колонки з фіксованими розмірами карток, захистом від перекосу сітки та обрізанням довгих назв (до 30 символів).
- **Колірна диференціація стану карток**:
  - **Прослухана станція** — глибокий чорний фон (`#000000`), темний бейдж із галочкою (`#1 ✓`).
  - **Не прослухана станція** — темно-сірий фон (`#282b30`) зі стандартною рамкою (`#3c4148`).
  - **Нова станція** — темно-зелений фон (`#162d1d`), яскраво-зелена рамка (`#2ea043`), значок зі зірочками (`#✨`) та зелена кнопка «Грати».
  - **Активна станція** — чорний фон, пульсуючий райдужний неоновий контур, червона кнопка «Стоп».
- **Стиль «✨ Нова вкладка»**:
  - Окремий чіп у панелі стилів для миттєвої фільтрації нових (зелених) станцій.
  - Автоматично активується при імпорті з M3U або додаванні станції вручну та залишається постійно відкритою.
- **Модальне вікно вибору країн (5 колонок)**:
  - Відкривається кнопкою `🌍 Усі країни ▼`.
  - 5 колонок країн зі збільшеним удвічі шрифтом (19px bold).
  - Без чекбоксів: обрані країни світяться яскраво-синім неоновим кольором.
  - Підтримка мульти-вибору (одна, дві чи довільна кількість країн одночасно).
- **Збереження стану (`app_state.json`)**:
  - Надійне збереження всіх кольорів, прослуханих/нових станцій, вибраних країн та активної вкладки між перезапусками додатку.
- **Розумна навігація та повна підтримка клавіатури**:
  - Автоматичне позиціонування на останній відіграній картці при старті.
  - `Tab` / `Shift + Tab` для миттєвого перемикання між рядком пошуку та сіткою карток.
  - Стрілки `◀ ▲ ▼ ▶`, `Home`, `End`, `Page Up / Page Down`, `Space` / `Enter` (відтворення/пауза), `Delete` / `D` (позначити на видалення), `Insert` (додати станцію).
- **Лаконічна верхня панель керування**:
  - Статистика бази станцій `Всього: N | Позначено до видалення: M`.
  - Інформація про трек, що грає, з можливістю виділення та копіювання назви пісні (`📋`).
  - Кнопка швидкого додавання `➕ Додати з M3U` та таймер автопереходу між станціями (3–60 сек).
- **Єдине вікно редагування та додавання станцій (`EditStationDialog`)**:
  - Відкривається правою кнопкою миші над будь-якою карткою або натисканням на картку `+ Додати станцію`.
  - Валідація протоколів (`http`, `https`, `mms`, `rtmp`) та багаторівневий захист від дублікатів (у поточній базі та серед видалених `station_delete.json`).
- **Автоматична діагностика неробочих потоків**:
  - Перехоплення помилок FFmpeg (404 Not Found, помилка кодека) та таймаут підключення (6 секунд).
  - Автоматичне маркування битих потоків та автоперехід на наступну робочу станцію.
- **Імпорт M3U / M3U8**:
  - Пакетний імпорт плейлистів з прогрес-баром, дедуплікацією та інтеграцією у стиль «✨ Нова вкладка».

## 🚀 Швидкий старт

### Веб-плеєр
1. Відкрийте `index.html` у браузері або запустіть локальний сервер:
   ```bash
   python3 -m http.server 8000
   ```
2. Перейдіть за адресою `http://localhost:8000/`.

### Десктопний Radio Manager
1. Встановіть необхідні залежності:
   ```bash
   pip install PyQt6
   ```
   *(Переконайтеся, що в системі встановлено аудіобібліотеки FFmpeg / GStreamer).*
2. Запустіть менеджер:
   ```bash
   python3 radio_manager.py
   ```

## 🛠 Технологічний стек

- **Веб**: HTML5 Audio API, CSS3 Grid / Custom Properties, Vanilla JavaScript (ES6+), SVG.
- **Десктоп**: Python 3.10+, PyQt6 (Widgets, Multimedia, Custom Styles/Painting), FFmpeg backend.
- **Дані**: JSON (`stations.json`), стан (`app_state.json`), архів видалених (`station_delete.json`), M3U / M3U8 парсинг.
- **Архітектурний розвиток**: Перехід на SQLite (WAL) + FTS5 та віртуалізований пул віджетів (див. `PLAN.md`).
