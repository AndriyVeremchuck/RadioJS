# 🎵 RadioJS

**RadioJS** — це сучасний, швидкий та стильний веб-додаток для онлайн-прослуховування 100 найкращих радіостанцій України та Світу.

---

## 🌟 Особливості

- **100 відібраних радіостанцій**:
  - 🇺🇦 **Україна**: національні та регіональні станції без дублювання ефіру (Хіт FM, Армія FM, Радіо ROKS, Радіо Байрактар, Радіо Промінь, Радіо Культура, Країна FM, Lux FM, FM Галичина та ін.).
  - 🌍 **Світ**: топ-станції Європи та США (NRJ France, Capital FM UK, 1LIVE Germany, KIIS FM LA, Z100 New York, Sunshine Live Trance/Techno/90s, Rock Antenne, Radio BOB!, Radio Caroline, Virgin Radio Classic Rock, SomaFM Groove Salad, Smooth Chill UK, Heart 90s/00s тощо).
- **Стильний та плавний дизайн**:
  - Напівпрозорий скляний неоморфізм / glassmorphism.
  - Плавне фонове відео у релакс-темпі (швидкість `0.45`).
  - Чіткі локальні логотипи та вбудований пул із 20 тематичних векторних SVG-плейсхолдерів для резервного відображення.
- **Унікальні анімації**:
  - При наведенні курсору картка плавно підсвічується та масштабується.
  - При відтворенні активна картка зменшується на 10% і вібрує по центру як дзвіночок із золотим світінням та еквалайзером.
- **Оптимізований аудіо-рушій**:
  - Керування відтворенням/паузою в один клік прямо на картці.
  - Автоматичне скидання з'єднань (`resetAudioStream`) для захисту від блокування браузерних HTTP-лімітів підключень.
- **Повна адаптивність**:
  - 5 колонок на моніторах і ПК, адаптація під 4, 3 та 2 колонки на планшетах та смартфонах.
- **Без сторонніх бібліотек та реклами** — чистий нативний HTML/CSS/JS.

---

## 🚀 Швидкий старт

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/AndriyVeremchuck/RadioJS.git
   ```
2. Відкрийте `radio.html` у будь-якому браузері (або запустіть локальний сервер):
   ```bash
   python3 -m http.server 8000
   ```
3. Відкрийте у браузері `http://localhost:8000/radio.html` та насолоджуйтесь музикою!

## 🛠 Технологічний стек

- **HTML5** (адаптивна семантична розмітка, Audio/Video API)
- **CSS3** (CSS Grid, Backdrop Blur, Keyframe анімації, медіа-запити)
- **Vanilla JavaScript** (потокове керування Icecast/HLS аудіо, обробка помилок мережі, динамічний хеш плейсхолдерів)
- **SVG & Vector Graphics** (власний пул музичних векторних ілюстрацій)
