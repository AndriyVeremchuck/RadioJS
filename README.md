## ✨ Особливості веб-сторінки

- 🇺🇦 **109 перевірених станцій:** Повний каталог популярних національних та регіональних українських радіостанцій (Hit FM, Kiss FM, Radio ROKS, NRJ, Radio Jazz, Байрактар, ТАКТ та багато інших).
- 🔒 **100% захищені HTTPS-потоки:** Усі аудіопотоки оптимізовані та транслюються через прямі захищені CDN без блокувань *Mixed Content* чи помилок браузера.
- 🎨 **Справжні логотипи:** Кожна радіостанція має чіткий фірмовий логотип з адаптивним підлаштуванням під картку.
- ⚡ **Миттєве відтворення:** Запуск і перемикання станцій в один клік без переривань і перезавантаження сторінки.
- 💫 **Живий неоновий інтерфейс:** Світлові відблиски, інтерактивна підсвітка та еквалайзер для активної радіостанції, делікатний фоновий відеоряд.
- 📱 **Повна адаптивність:** Зручно користуватися як на комп'ютері, так і на планшеті чи смартфоні.

## 🚀 Як користуватися

1. **Онлайн (без встановлення):**  
   Перейдіть за посиланням: [andriyveremchuck.github.io/RadioJS](https://andriyveremchuck.github.io/RadioJS/)
2. **Локально на комп'ютері:**  
   Відкрийте файл `index.html` у будь-якому сучасному браузері або запустіть локальний сервер:
   ```bash
   python3 -m http.server 8080
   ```
   та перейдіть за адресою `http://localhost:8080/`.

## 🛠 Технології

- **HTML5 Audio API** (нативне потокове відтворення аудіо)
- **CSS3 Grid & Flexbox** (адаптивна сітка, плавні переходи та неонові ефекти)
- **Vanilla JavaScript (ES6+)** (керування потоками, перевірка стану та авто-відновлення)
- **Векторна графіка SVG** (висока якість на retina-дисплеях)

## 🖥️ Десктопний додаток: Radio Manager (PyQt6 / Native ELF)

Проєкт також містить потужний настільний менеджер радіостанцій для керування великою базою (понад 2 950 станцій з усього світу):

### Основні можливості Radio Manager:
- ⚡ **Миттєвий запуск (O(1) індексація):** База з тисяч станцій завантажується за ~0.15 секунди без підвисань інтерфейсу.
- 📥 **Інтелектуальний імпорт M3U-плейлистів:**
  - **Трикрокова верифікація країни:** перевірка назви файлу → паралельне зчитування ICY-метаданих з живого аудіопотоку → аналіз TLD-доменів, мережі та назви.
  - **Підтримка національних абеток:** Польща, Чехія, Словаччина, Туреччина, Румунія, Німеччина, Скандинавія, Іспанія, Японія, Корея тощо.
  - **Релігійно-ісламський фільтр:** станції з ісламською тематикою автоматично закріплюються за Саудівською Аравією.
  - **Автоматична дедуплікація:** відсіювання внутрішніх повторів файлу, поточних станцій бази та архіву видалених (`station_delete.json`).
- 🧹 **Санітизація та збагачення метаданих:**
  - Автоматичне прибирання сміття з назв: префіксів треків (`1] `) та бітрейту (`- 128 kbit/s`) зі збереженням FM-частот.
  - Розумне автопризначення красивих жанрових категорій з іконками (`🎸 Rock`, `🎤 Pop`, `🎧 Electro`, `🎷 Jazz`, `☕ Relax` тощо).
- 🎨 **Візуальні стани карток:**
  - `Темно-сірий`: непрослухана станція.
  - `Зелений`: нова додана станція (автоматично групується у вкладку «✨ Нова вкладка»).
  - `Глибокий чорний`: прослухана станція.
  - `Неоновий райдужний контур`: активна станція, що грає в даний момент.
- 🎹 **Повне керування клавіатурою:** Стрілки навігації, `Space`/`Enter` для відтворення, `Delete` для позначення на видалення, `Insert` для додавання станції, `Tab` для пошуку.

### Запуск та компіляція Radio Manager:
1. **Запуск готового бінарного файлу:**
   ```bash
   ./radio_manager
   ```
2. **Компіляція у нативний ELF-файл:**
   ```bash
   ./build.sh
   ```
